Portfolio profesional e interactivo de **Gustavo Rojas** — *AI & Full-Stack Developer* y *Tech Lead en Breakpoint Creativa*. Desarrollado con **React**, **TypeScript**, **Three.js** y **GSAP**, ofreciendo una experiencia inmersiva en 3D, animaciones fluidas y una presentación detallada de proyectos tecnológicos de alto impacto.

---

## 🚀 Características Principales

- 🎨 **Experiencia 3D Interactiva**: Escenas e interacciones tridimensionales potencias por Three.js, React Three Fiber y físicas.
- ⚡ **Alto Rendimiento**: Construido sobre Vite para compilaciones e itinerancia ultrarrápidas.
- 🎯 **Showcase de Proyectos**: Presentación interactiva de proyectos destacados:
  - **Breakpoint Creativa**: Plataforma Web & Soluciones IA.
  - **AeroCast AI**: Seguridad operacional UAV y monitoreo troposférico.
  - **SaludMental Tech Analytics**: Dashboards de salud mental e indicadores en la industria tecnológica.
  - **VocacioNext Bot**: Plataforma de orientación vocacional basada en el modelo RIASEC.
  - **Enterprise AI Gateway Router**: Enrutamiento inteligente de LLMs, protección PII y métricas financieras.
  - **Ajedrez AI**: Juego de ajedrez 3D con IA (Minimax + Poda Alfa-Beta) y diseño Dark Neon.
  - **Enterprise QA Testing Suite**: Plataforma automatizada de pruebas E2E con Pytest y Selenium 4.
- 📱 **Diseño Responsive & Fluid Animations**: Adaptado para dispositivos móviles y de escritorio utilizando GSAP y Lenis Scroll.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend Core**: React 18, TypeScript, HTML5, CSS3, Vite
- **Gráficos 3D & Animaciones**: Three.js, `@react-three/fiber`, `@react-three/drei`, `@react-three/rapier`, GSAP, Lenis
- **Analítica & Herramientas**: Microsoft Clarity, Google Analytics 4 (GA4), Lucide / React Icons
- **Backend & Integraciones de IA**: Python (FastAPI), Node.js, Llama 3.3, Minimax AI

## 💻 Instalación y Ejecución Local

### Prerrequisitos
- Node.js (v18 o superior)
- npm o yarn

### Pasos

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/gusok2015/Portfolio-Actualizado-Gustavo-Rojas.git
   cd Portfolio-Actualizado-Gustavo-Rojas
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:5173/](http://localhost:5173/) en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
